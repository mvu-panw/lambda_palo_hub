What AI Runtime Security does

  • Discover: automatically maps AI applications, models, users, datasets, and plugins, and how they connect.
  • Model protection: blocks direct and indirect prompt injection, including goal hijacking and jailbreak attempts.
  • Data protection: detects 1,000+ predefined data patterns in prompts and responses to prevent leakage.
  • Application protection: blocks malicious URLs in model input and output, including URLs that poisoned RAG data could produce.
  • Agent and database controls: secures AI agents and limits which query types (create, read, update, delete) AI-generated database calls can run.

Two ways to deploy

Network intercept: inline inspection of traffic between apps, models, and the internet. It uses the same App-ID and cloud-delivered security services as the NGFW, and adds east-west inspection for containerized and virtualized workloads.

API intercept: developers call the AIRS API directly from their application code. This works with any public or private model, adds no decryption overhead, and can return custom responses when a threat is detected.
