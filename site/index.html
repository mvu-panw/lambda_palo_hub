Network security for AI infrastructure

Every Palo Alto Networks next-generation firewall runs PAN-OS, so policy, threat prevention, and management work the same way from a branch PA-1400 up to a PA-5500 in the data center.

  • Single-pass architecture: performance stays predictable with security services turned on.
  • Post-quantum ready: PQC decryption and site-to-site VPN using NIST ML-KEM, ML-DSA, and SLH-DSA.
  • One console: manage everything from Strata Cloud Manager or Panorama.

Security for the AI you build and run

Prisma AIRS protects AI applications, models, agents, and data across their lifecycle:

  • AI Runtime Security: blocks prompt injection, data leakage, and malicious URLs at runtime.
  • AI Model Security: scans models for threats before you deploy them.
  • AI Red Teaming: runs automated adversarial testing against your AI apps and agents.
