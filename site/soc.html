Cortex XSIAM

An AI-driven security operations platform that replaces a stack of separate SOC tools with one data model, one console, and one automation engine. Palo Alto Networks runs its own SOC on it.

  • One platform: SIEM, SOAR, XDR, cloud detection and response (CDR), network detection and response (NDR), identity threat detection and response (ITDR), exposure management, email security, and threat intelligence.
  • Data foundation: the Cortex Extended Data Lake (XDL) has 1,100+ integrations, and it correlates, normalizes, and enriches data as it arrives. Federated search also covers data stored outside XDL.
  • Detection: 13,300+ detectors, including 2,900 machine learning models. Low-fidelity alerts are handled automatically, and the rest are grouped into prioritized cases.
  • Automation: 1,300+ out-of-the-box playbooks, plus agentic playbooks that embed LLM tasks, with optional human approval. The datasheet cites up to 75% less manual SOC effort.
  • Agentic Assistant: built on Cortex AgentiX, it gives analysts a fleet of AI agents that investigate and act while humans stay in control.
  • Managed option: Unit 42 Managed XSIAM provides 24/7 coverage.

Cortex Agentic Endpoint Security

An AI-native control plane for the software modern endpoints actually run: AI coding agents, browser and IDE extensions, MCP servers, models, and open-source packages. Traditional EDR doesn't see these.

  • Discover shadow AI: inventories AI agents and their runtime activity, MCP servers, models, browser extensions, and IDE plugins across the fleet.
  • Govern AI agents: pre-execution hooks stop agents such as Cursor and Claude Code from reading local cloud secrets or running destructive commands.
  • Stop supply-chain attacks: blocks malicious npm and PyPI packages before they reach developer machines.
  • Context-aware risk: an AI risk engine scores every artifact on origin, vulnerabilities, and behavior. The scores are checked against NVD, Google OSV, and the OpenSSF Scorecard.
  • No developer friction: a blocked install becomes a "Request Approval" button that opens a ticket in Jira or ServiceNow.
  • Deployment: extends Cortex XDR natively, or runs alongside a third-party EDR/XDR without replacing it.
